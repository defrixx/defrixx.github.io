# Ревью безопасности

Используйте для проверки безопасности PR или репозитория. Ассистент прослеживает движение данных через границы доверия, проверяет гипотезы, оценивает последствия и готовит рекомендации по исправлению.

[Исходники скилла](https://github.com/defrixx/Product-security-skills/tree/main/skills/security-review) | [Как установить](../overview.ru.md)

## Входные данные

Для PR укажите базовый и целевой коммиты; для проверки репозитория зафиксируйте коммит и состояние рабочей копии. Укажите проверяемые компоненты, исключения и доступные сведения о конфигурации и работе системы.

## Охват и зависимости

Моделирование угроз, поиск уязвимостей, проверка достижимости и предпосылок атаки, анализ последствий и приоритизация замечаний. Дополнительный скрипт `scripts/pr_context.py` фиксирует локальный контекст Git, но не ищет уязвимости. Ему нужны Python 3.9+ и Git.

## Пример запроса

> Используй security-review для этого PR с указанными базовым и целевым коммитами. Раздели новые и ранее существовавшие проблемы. Подготовь подтвержденные замечания, гипотезы, доказательства и непроверенные области, не меняя код.

## Результат и ограничения

Для замечаний указываются предпосылки, последствия, уверенность в выводе, исправление и критерии его проверки. Сигнал сканера остается гипотезой до подтверждения. Запрос на ревью сам по себе не разрешает менять код, атаковать внешние системы, оставлять комментарии в PR или публиковать отчет.
