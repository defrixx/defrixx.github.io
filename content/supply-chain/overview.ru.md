# Цепочка поставки

Выберите документ по задаче: безопасность pipeline CI/CD, build provenance или безопасность контейнерного образа. Полная проверка поставки охватывает все три области.

| Задача | Документ | Охват проверки |
| --- | --- | --- |
| Проверить pipeline CI/CD | [Безопасность CI/CD](./ci-cd-security/playbook.ru.md) | Недоверенные запросы на слияние, события запуска, изоляция исполнителей, кеши, артефакты, федерация и привязка согласования к дайджесту релиза. |
| Проверить build provenance | [SLSA и build provenance](./slsa-provenance/overview.ru.md) | Уровни SLSA Build, границы доверия CI/CD и связь артефакта с provenance его сборки. Рассматривает распространение аттестаций, идентификаторы доверенных систем сборки и проверку provenance перед развертыванием. |
| Проверить контейнерные образы | [Контейнерные образы](./container-image-security/playbook.ru.md) | Dockerfile, базовые образы, зависимости, секреты сборки, дайджесты и образы для нескольких архитектур. Охватывает сканирование, подписи, передачу образов через реестры и проверки образа перед развертыванием. |

## Как выбрать документы

- Для проверки исполнителей, разрешений процессов и передачи артефактов начните с плейбука CI/CD.
- Если вопрос касается происхождения артефакта и процесса его сборки, начните с обзора SLSA.
- Если проверяете Dockerfile, контейнерный образ или его передачу через реестр, начните с плейбука безопасности образов.
- Для проверки пути от сборки до поставки используйте все три документа: CI/CD описывает границы исполнения и развертывания, SLSA задает контекст provenance, а плейбук образов раскрывает работу с контейнерными артефактами.

## Когда нужны другие разделы

Критерии допуска к выпуску описаны в плейбуке [управления выпуском](../review/release-governance/playbook.ru.md). Настройки среды выполнения проверяйте по документам раздела [безопасности платформы](../platform-security/overview.ru.md).
