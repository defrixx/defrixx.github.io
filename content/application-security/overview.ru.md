# Безопасность приложений

Выберите плейбук для проверяемой части приложения: кода, API, бизнес-логики, входа в систему или браузерного клиента. OWASP Top 10 поможет сверить охват проверки.

| Задача | Документ | Охват проверки |
| --- | --- | --- |
| Проверить код | [Ревью кода](./secure-coding/code-review/playbook.ru.md) | Проверка изменений и подтверждение замечаний |
| Проверить API | [Безопасность API](./api/api-security-patterns/playbook.ru.md) | Меры защиты на границах API |
| Проверить бизнес-логику | [Безопасность бизнес-логики](./business-logic/business-logic-abuse/playbook.ru.md) | Злоупотребления функциями приложения |
| Проверить вход и делегирование доступа | [OIDC и OAuth](./identity/oidc-oauth/playbook.ru.md) | Интеграции OIDC и OAuth |
| Проверить защиту в браузере | [Защита в браузере](./web/browser-security/playbook.ru.md) | Браузерные механизмы защиты веб-приложения |
| Проверить охват рисков веб-приложения | [OWASP Top 10](./web/owasp-top-10/playbook.ru.md) | Категории OWASP Top 10 и соответствующие проверки |

## Как сочетать документы

- Для проверки PR начните с ревью кода, затем выберите документы по затронутым механизмам: API, бизнес-логике, OIDC/OAuth или браузерной защите.
- Для проверки API используйте профильный плейбук вместе с проверкой бизнес-логики, если задача затрагивает последовательность действий или правила работы продукта.
- Для веб-приложения дополните профильные проверки документом по браузерной защите. OWASP Top 10 используйте для сверки категорий рисков, охваченных проверкой.
