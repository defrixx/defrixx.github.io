# Безопасность приложений

Выберите плейбук для проверяемой части приложения: кода, API, бизнес-логики, входа в систему или браузерного клиента. OWASP Top 10 поможет сверить охват проверки.

| Задача | Документ | Охват проверки |
| --- | --- | --- |
| Проверить код | [Ревью кода](./secure-coding/code-review/playbook.ru.md) | Обработка входных данных, передача данных интерпретаторам, авторизация, сессии, файлы, секреты и зависимости в изменяемом коде. Включает проверку достижимости опасных операций и сбор подтверждающих материалов для замечаний по результатам ревью. |
| Проверить API | [Безопасность API](./api/api-security-patterns/playbook.ru.md) | REST, SOAP/XML, GraphQL, вебхуки и gRPC: аутентификация, доступ к объектам, проверка схем, ограничения запросов и журналирование. Рассматривает границы доверия между клиентом, шлюзом и внутренними сервисами. |
| Проверить бизнес-логику | [Безопасность бизнес-логики](./business-logic/business-logic-abuse/playbook.ru.md) | Захват учетных записей, злоупотребления регистрацией и промоакциями, изоляция арендаторов и права на бизнес-операции. Разбирает переходы состояний, повторное выполнение запросов, идемпотентность и обнаружение злоупотреблений. |
| Проверить вход и делегирование доступа | [OIDC и OAuth](./identity/oidc-oauth/playbook.ru.md) | Сценарии входа и делегирования доступа, перенаправления, PKCE, проверка токенов, областей доступа и получателей. Охватывает идентификацию пользователей в пределах конкретного издателя, passkeys, надежность аутентификации, восстановление доступа, требования к отзыву доступа и границы доверия между клиентом, сервером авторизации и API. |
| Проверить защиту в браузере | [Защита в браузере](./web/browser-security/playbook.ru.md) | CSP, CORS, cookie, встраивание страниц и сторонние скрипты. Рассматривает браузерные границы доверия, зависимости клиентской части и проверку фактически применяемых заголовков и политик. |
| Проверить охват рисков веб-приложения | [OWASP Top 10](./web/owasp-top-10/playbook.ru.md) | Контроль доступа, инъекции, криптография, конфигурация, компоненты, целостность, журналирование и SSRF. Связывает категории OWASP Top 10 с проверками и признаками проблем, чтобы оценить охват ревью. |

## Как сочетать документы

- Для проверки PR начните с ревью кода, затем выберите документы по затронутым механизмам: API, бизнес-логике, OIDC/OAuth или браузерной защите.
- Для проверки API используйте профильный плейбук вместе с проверкой бизнес-логики, если задача затрагивает последовательность действий или правила работы продукта.
- Для веб-приложения дополните профильные проверки документом по браузерной защите. OWASP Top 10 используйте для сверки категорий рисков, охваченных проверкой.
