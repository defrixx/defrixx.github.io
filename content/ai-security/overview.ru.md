# Как выбрать документ по безопасности ИИ

Начните с вопроса, который нужно решить. Документы охватывают три направления: безопасность функций ИИ в продукте, контроль действий агентов и применение ИИ в инженерной работе.

| Документ | Главный вопрос | Область применения |
| --- | --- | --- |
| [Обзор безопасности ИИ](securing-ai/overview.ru.md) | Как защитить функцию ИИ внутри продукта? | Общая программа безопасности: данные, модели, инфраструктура, жизненный цикл и проверка мер защиты |
| [Безопасность агентного ИИ](agentic-ai/playbook.ru.md) | Как контролировать действия, память и полномочия агента? | Авторизация действий, инструменты, память, изоляция, подтверждения, откат и аварийное отключение |
| [Безопасность MCP](mcp-security/playbook.ru.md) | Как проверить подключение инструментов через MCP? | Реестр серверов, возможности протокола, схемы развертывания, авторизация и журналирование |
| [Безопасная разработка с ИИ](ai-assisted-development/playbook.ru.md) | Как безопасно применять ИИ в разработке? | Контекст ассистента, сгенерированные изменения, зависимости, проверки перед слиянием и выпуском |
| [Скиллы для задач безопасности](../ai-automation/security-skills/overview.ru.md) | Как запустить конкретный вспомогательный процесс? | Инструкции для ассистента по разработке, ревью безопасности или подготовке очищенной копии материалов |

## Если задача затрагивает несколько документов

- Для функции ИИ в продукте начните с обзора безопасности ИИ. Если модель выполняет действия через инструменты, дополнительно используйте плейбук безопасности агентного ИИ, а при подключении через MCP — плейбук безопасности MCP.
- Для агента разработки начните с плейбука безопасной разработки с ИИ. Полномочия, память и среду выполнения проверьте по плейбуку безопасности агентного ИИ, а подключения MCP — по плейбуку безопасности MCP.
- Для выполнения конкретной инженерной задачи выберите подходящий скилл для задач безопасности. Критерии оценки результата берите из соответствующего плейбука; инструкции скилла помогают организовать работу.

## Где найти классификацию угроз

[Обзор OWASP LLM Top 10 (2025)](owasp-llm-top-10/overview.ru.md) объясняет категории угроз и различия между ними. Используйте его как общий словарь при моделировании угроз и ревью. Меры защиты и способы проверки описаны в профильных документах выше.
