Используйте для проверки папки или подготовки отдельной копии к передаче. Ассистент классифицирует потенциально чувствительные значения и при необходимости применяет локальный скрипт с ограниченной областью обработки.

[Исходники скилла](https://github.com/defrixx/Product-security-skills/tree/main/skills/sensitive-data-cleanup) | [Как установить](/Product-security-playbook/ru/ai-automation/security-skills/overview/)

## Входные данные

Укажите исходную папку, исключения, правила определения чувствительных данных и новый выходной каталог вне исходного дерева. Выберите поиск без изменений, очистку текста или удаление только метаданных JPEG/PNG.

## Охват и зависимости

Очистка текста UTF-8, JSON, JSONL и CSV; отдельный режим удаляет метаданные JPEG/PNG, сохраняя закодированные пиксели. Для `scripts/cleanup.py` нужны Python 3.9+, стандартная библиотека и файловые операции POSIX. Перед запуском прочитайте описание ограничений скрипта.

## Пример запроса

> Используй sensitive-data-cleanup для подготовки этой папки к передаче в новом соседнем каталоге. Сохрани оригиналы. Укажи замены, пропущенные файлы, ошибки и оставшуюся неопределенность, не раскрывая исходные чувствительные значения.

## Результат и ограничения

При запросе очистки создаются отдельная копия, отчет без исходных чувствительных значений и описание охвата. Неподдерживаемые файлы и файлы с ошибками пропускаются с отражением в отчете. Содержимое изображений не ретушируется; удаление метаданных может изменить отображение ориентации и цвета. Очистка не отзывает раскрытые учетные данные, не удаляет историю Git и резервные копии и не гарантирует обнаружение всех персональных данных или работоспособность копии.

Срабатывание средства поиска само по себе не подтверждает наличие чувствительных данных: найденное значение оценивается по контексту и выбранным правилам обработки. Пропущенный файл или файл неподдерживаемого формата остается непроверенным, даже если в обработанных файлах совпадений не найдено.
