Начните с вопроса, который нужно решить. Документы охватывают три направления: безопасность функций ИИ в продукте, контроль действий агентов и применение ИИ в инженерной работе.

| Документ | Главный вопрос | Область применения |
| --- | --- | --- |
| [Обзор безопасности ИИ](/Product-security-playbook/ru/ai-security/securing-ai/overview/) | Как защитить функцию ИИ внутри продукта? | Данные, модели, инфраструктура и жизненный цикл функции ИИ: от определения границ доверия до проверки мер защиты. Помогает организовать общую программу безопасности и распределить ответственность за ее выполнение. |
| [Безопасность агентного ИИ](/Product-security-playbook/ru/ai-security/agentic-ai/playbook/) | Как контролировать действия, память и полномочия агента? | Авторизация действий, инструменты, память и изоляция среды выполнения агента. Рассматривает подтверждение чувствительных операций, откат, аварийное отключение и данные для подтверждения результатов проверки поведения агента. |
| [Безопасность MCP](/Product-security-playbook/ru/ai-security/mcp-security/playbook/) | Как проверить подключение инструментов через MCP? | Реестр MCP-серверов, схемы развертывания, авторизация и границы доверия к инструментам, ресурсам и промптам. Включает проверку транспортного уровня, изменений набора возможностей сервера, журналирования и запросов дополнительных данных у пользователя. |
| [Безопасная разработка с ИИ](/Product-security-playbook/ru/ai-security/ai-assisted-development/playbook/) | Как безопасно применять ИИ в разработке? | Контекст ассистента, чувствительные данные, сгенерированный код, зависимости и полномочия агента разработки. Охватывает независимую проверку изменений, применение скиллов и подтверждение результатов проверок перед слиянием изменений и выпуском. |
| [Скиллы для задач безопасности](/Product-security-playbook/ru/ai-automation/security-skills/overview/) | Как запустить конкретный вспомогательный процесс? | Выбор и установка инструкций для разработки, ревью безопасности или подготовки очищенной копии материалов. Для каждой задачи указаны входные данные, ожидаемый отчет, вспомогательные средства и ограничения результата. |

## Если задача затрагивает несколько документов

- Для функции ИИ в продукте начните с обзора безопасности ИИ. Если модель выполняет действия через инструменты, дополнительно используйте плейбук безопасности агентного ИИ, а при подключении через MCP — плейбук безопасности MCP.
- Для агента разработки начните с плейбука безопасной разработки с ИИ. Полномочия, память и среду выполнения проверьте по плейбуку безопасности агентного ИИ, а подключения MCP — по плейбуку безопасности MCP.
- Для выполнения конкретной инженерной задачи выберите подходящий скилл для задач безопасности. Критерии оценки результата берите из соответствующего плейбука; инструкции скилла помогают организовать работу.

## Где найти классификацию угроз

[Обзор OWASP LLM Top 10 (2025)](/Product-security-playbook/ru/ai-security/owasp-llm-top-10/overview/) объясняет категории угроз и различия между ними. Используйте его как общий словарь при моделировании угроз и ревью. Меры защиты и способы проверки описаны в профильных документах выше.
