Read the playbooks, choose a task and download templates. Run skills and tools in your environment after reading their input contracts. This static site accepts no projects, tokens or personal data and performs no visitor assessments.

## Workflow

Record scope and revision, select applicable requirements, run authorized checks locally and retain results. Use the synthetic example for your [chosen scenario](/en/hub/tasks/overview/), then replace its teaching assumptions with your project's contract. The [catalogue](/en/hub/catalogue/overview/) helps select an independent skill or tool. Publishing reports, changing code and external actions need an appropriate task; reading a playbook starts none of these actions.

## Safety and decisions

Keep real secrets out of public examples and issue reports. Execute commands and checks only in the agreed scope; assess network and production access separately. Synthetic expectations, local test observations and real release approval are separate records. The responsible human makes the release decision.
